# Death Zone 

## 1. კონცეფცია, ამოცანა და მომხმარებელი

### რეპორტი

ეს პროექტი ეხება ჰიმალაის 8000+ მეტრიან მწვერვალებზე ასვლის რეალური რისკის ანალიზს (1905–2024)  არა საშუალო სტატისტიკით, არამედ იმის მიხედვით, ვინ ხარ სისტემაში: კლიენტი თუ დაქირავებული პერსონალი.

### რა მთავარ ამოცანას ემსახურება / რა პრობლემას ჭრის

პრობლემა ისაა, რომ როდესაც ადამიანი გეგმავს 8000+ მეტრზე ასვლას, არ არსებობს ისეთი ბაზა ან ანალიზი, საიდანაც გაიგებს:

- რეალურად რამდენად საშიშია კონკრეტული მწვერვალი კონკრეტულ სეზონზე: არა ერთი საშუალო რიცხვით, რომელიც კლიენტისა და დაქირავებულის სრულიად განსხვავებულ გამოცდილებას მალავს;
- რომელ ოპერატორს აქვს რეალურად საკმარისი გამოცდილება ამ კონკრეტულ მარშრუტზე, და არა შემთხვევითი 2-3 ექსპედიციის სტატისტიკა, რომელიც წარმატებას ან წარუმატებლობას ლატარიად აქცევს;
- რომელი ფაქტორი (სეზონი, ასაკი, ჟანგბადი) რეალურად განსაზღვრავს გადარჩენას, და არა მხოლოდ კორელაციას წარმატებასთან.

გამოქვეყნებული სტატისტიკა ჩვეულებრივ ერთ საშუალო რიცხვს იძლევა („ევერესტზე სიკვდილიანობა X%-ია"), რომელიც ორ სრულიად სხვადასხვა რისკ-პროფილს ერთმანეთში ურევს. ეს რეპორტი ამ ორ ჯგუფს ყველგან განცალკევებულად აჩვენებს და პასუხობს კითხვას, რომელსაც არცერთი საჯარო წყარო ცალკე არ სვამს.

## 2. შინაარსობრივი ნაწილი და მიგნებები

### გვერდი 1: მწვერვალებზე ასვლის რისკის ანალიზი

**რა ინფორმაციის წაღება შეეძლება მომხმარებელს:**
მომხმარებელი ხედავს, როგორ შეიცვალა ასვლების მასშტაბი დროში და, რაც მთავარია  როგორ განსხვავდება რისკი როლის მიხედვით (კლიენტი vs დაქირავებული პერსონალი) თითოეულ მწვერვალზე.

**მიგნება 1:**
1953 წელს ევერესტზე სულ 2 ადამიანი ავიდა; 2024 წლისთვის ეს რიცხვი 12,712-ია — ერთი დღევანდელი სეზონი აღემატება პირველი ოცდაათი წლის ჯამურ შედეგს. მაგრამ ზრდასთან ერთად რისკის განაწილებაც შეიცვალა: 1970-იან წლებში დაქირავებული პერსონალი (შერპები) კლიენტზე ექვსჯერ მეტად იღუპებოდა (17.0% vs 2.9%), ხოლო 2010-იან წლებში ეს ორი რიცხვი თითქმის გათანაბრდა (0.85% vs 0.83%). ეს მომხმარებელს (სააგენტოს ან დამზღვევს) აძლევს სიგნალს, რომ კომერციალიზაციამ მთა არ გახადა უსაფრთხო — შეცვალა ის, ვინ ატარებს რისკს.

### გვერდი 2: მწვერვალზე ასვლის შანსის ანალიზი

**რა ინფორმაციის წაღება შეეძლება მომხმარებელს:**
მომხმარებელი აფასებს, რომელი ფაქტორი (სეზონი, ასაკი, ჟანგბადი) რეალურად განსაზღვრავს წარმატებას, და როგორ იკითხება ეს რიცხვი სწორად — არა მარტივი კორელაციით.

**მიგნება 2:**
დამატებითი ჟანგბადის გამოყენებისას წარმატების მაჩვენებელი 80.8%-ია, უამისოდ — მხოლოდ 15.2%. სეზონურად, გაზაფხულზე წარმატება 48.7%-ია, შემოდგომაზე — 35.9%, ხოლო ზამთარსა და ზაფხულს შორის განსხვავება უმნიშვნელოა (7.7% და 7.5%). თუმცა მნიშვნელოვანია სწორი წაკითხვა: ჟანგბადის ეფექტი არ არის მხოლოდ ბალონის დამსახურება — ბალონით ასული ჩვეულებრივ მომზადებულ კომერციულ ექსპედიციაშია, პერსონალთან ერთად, ხოლო უჟანგბადოდ ასულთა დიდი ნაწილი საერთოდ არ ცდილობს ბაზაზე ზემოთ ასვლას. ეს კორელაცია-vs-მიზეზობრიობის განსხვავებაა, რომელსაც რეპორტი ცალკე გამოყოფს.

## დეშბორდის აგებულება

ბადე: **6 სვეტი × 9 რიგი**, ყველა გვერდზე ერთი და იგივე ზოლები 
რიგი 0 ფილტრები, რიგი 1–2 მაჩვენებლები, რიგი 3–8 შიგთავსი.
ერთ ეკრანზე ეტევა, პრეზენტაციისას სქროლი არ სჭირდება.

### 1. მწვერვალებზე ასვლის რისკის ანალიზი
ორფერიანი დაჯგუფებული სვეტი თითო მთაზე კლიენტისა და დაქირავებულის
სიკვდილიანობა გვერდი-გვერდ. ორი დაგროვებითი ცხრილი აჩვენებს, როგორ
გაიზარდა ასვლების რიცხვი: **ევერესტზე 1953 წელს სულ 2 ადამიანი იყო ასული,
2024 წლისთვის — 12 712.** ერთი სეზონის შედეგი დღეს პირველი ოცდაათი წლის
ჯამს აღემატება.

### 2. მწვერვალზე ასვლის შანსის ანალიზი
რისკის კონვერგენცია ათწლეულებში, პლუს სამი ფაქტორი:

| სეზონი | წარმატება | | ასაკი | წარმატება |
|---|---:|:--|---|---:|
| გაზაფხული | 48.7% | | 10–24 | 57.5% |
| შემოდგომა | 35.9% | | 25–39 | 46.7% |
| ზამთარი | 7.7% | | 40–54 | 42.0% |
| ზაფხული | 7.5% | | 55+ | 29.3% |

ჟანგბადი ცალკე დგას: ბალონით **80.8%**, უამისოდ **15.2%** ყველაზე დიდი
სხვაობა სამივე ფაქტორს შორის, თუმცა იხილე „რაზე ღირს სიფრთხილე".

### 3. ოპერატორის ანალიზი
377 ოპერატორიდან მხოლოდ **57-ს აქვს 20+ ექსპედიცია**  და სწორედ ისინი
ფარავენ ჩანაწერების 81%-ს. ამიტომ ჩარტი 50+ კლიენტის ზღვარზეა შეზღუდული:
სამი კლიენტი და ერთი ასვლა „33%"-ია, რაც ლატარიაა, არა შედეგი.

### 4. 14x8000 კლუბის ანალიზი
**77 ადამიანმა** დაასრულა თოთხმეტივე რვაათასიანი, მათგან **24-მა
ჟანგბადის გარეშე.** ფოტოებიანი ცხრილი ერთი ალპინისტის არჩევით იშლება.

### 5. ქართველები 8000-ზე
**44 ექსპედიცია რვაათასიანებზე 1993 წლიდან, 22 ალპინისტი, 26 წარმატებული
ასვლა, 0 დაღუპული.**

ეს გვერდი განზრახ **არ** ეყრდნობა მარტივ `Citizenship = 'Georgia'` ფილტრს.
Himalayan Database მოქალაქეობას ისტორიულად აღრიცხავს: `Georgia`
პირველად 1993 წელს ჩნდება, მანამდე ქართველი ალპინისტი `USSR`-ით წერია.
არქივის 271 საბჭოთა ჩანაწერის შემოწმებამ ერთი ქართული გვარი იპოვა —
**აკაკი ხერგიანი, 1982, ევერესტი**, ლეგენდარული სვანი მთამსვლელების
ოჯახიდან. ამიტომ ქრონიკა 1982 წლიდან იწყება, არა 1993-დან.

მრავალფაქტიანი ვარსკვლავური სქემა: 11 ფაქტი + 3 განზომილება,
**ყველა კავშირი many-to-one**, ფაქტიდან განზომილებისკენ.

| განზომილება | გასაღები | კავშირი |
|---|---|---|
| `ds_dim_peak` | `PeakName` | 8 |
| `ds_dim_decade` | `Decade` | 8 |
| `ds_dim_nation` | `Nation` | 3 |
| `ds_agency_profile` | `Agency` | 1 |

**ორი წესი, რომელსაც მოდელი იცავს:**

1. **დროის განზომილება მხოლოდ ერთია** (ათწლეული). წლისა და ათწლეულის
   ორივე დამატება ერთი ფაქტიდან დრომდე ორ გზას შექმნიდა — ორაზროვნებას,
   რომელსაც Databricks კრძალავს.
2. **ფაქტი ფაქტს არ ებმის და განზომილება განზომილებას არ ებმის** —
   თორემ გრაფში ციკლი გაჩნდება.

`ds_dim_peak` სამ წყაროს კრებს ერთ ცხრილად (არქივი + ორი ვიკიპედიის
ცხრილი). სამივეს ერთი სტრიქონი აქვს ერთ მწვერვალზე, ამიტომ `LEFT JOIN`
სტრიქონებს არ ამრავლებს და გასაღები უნიკალური რჩება  ეს many-to-one
კავშირის აუცილებელი პირობაა.

## ტექნიკური გადაწყვეტილებები

**რატომ ითვლება პროცენტი dataset-ში, არა ჩარტში.**
Lakeview-ის ვიჯეტის `expression` მხოლოდ მარტივ აგრეგატს ითვლის 
`AVG(X)`, `SUM(X)`, `COUNT(*)`. რთული გამოსახულება
(`ROUND(100.0 * AVG(CAST(...)))`) იგნორირდება და ჩარტი ცარიელი რჩება.
ამიტომ dataset-ებში წინასწარ ჩნდება მზა სვეტები — `SuccessPct`,
`DeathPct`, `SummitFlag`, `DeathFlag`  ჩარტს კი მხოლოდ `AVG`/`SUM` რჩება.

**რატომ დგას მინიმალური შერჩევის ზღვრები.**
1900-იან წლებში არქივში სულ ოთხი დაქირავებულია და ოთხივე დაიღუპა  100%.
ამ ერთმა წერტილმა ღერძი 0–100-ზე გაწელა და მთელი თანამედროვე ისტორია
ნულთან მიაწება. ამიტომ კონვერგენციის ჩარტს აქვს „ათწლეული × როლი
მინიმუმ 100 ჩანაწერი" ზღვარი. იმავე მიზეზით: `Annapurna I Middle`-ს მთელ
ისტორიაში 41 ჩანაწერი აქვს, `Lhotse Middle`-ს 15  ისინი გვ.2-ის
dataset-ებიდან გამორიცხულია, რომ ფილტრში ვერც კი აირჩეოდნენ.

**რატომ არის დაგროვებითი ჯამი მწვერვალზე დაყოფილი.**
ფანჯარა (`PARTITION BY PeakName`) dataset-ის შიგნით ითვლება, ანუ
ფილტრამდე. გლობალური ჯამის შემთხვევაში მწვერვალის ფილტრი სტრიქონებს
მოაჭრიდა, „სულ დღემდე" კი მთელი არქივის რიცხვად დარჩებოდა  ცხრილი
დამაჯერებელ, მაგრამ მცდარ ციფრს აჩვენებდა.

## რაზე ღირს სიფრთხილე

**კორელაცია არ არის მიზეზობრიობა.** ჟანგბადით მავალთა წარმატება 80.8%-ია,
უჟანგბადოდ  15.2%. ეს ბალონის დამსახურება არ არის: ბალონით მავალი
ჩვეულებრივ კომერციულ ექსპედიციაშია, სადაც მარშრუტი მომზადებულია და
პერსონალი გვერდითაა, ხოლო „ჟანგბადის გარეშე" ჯგუფის დიდი ნაწილი ბაზიდან
ზემოთ საერთოდ არ ასულა.

**კონვერგენციის ზუსტი წაკითხვა.** რიცხვი ერთ *მონაწილეობაზეა* გათვლილი.
დაქირავებული ყინულზე რამდენჯერმე გადის, კლიენტი კი ჩვეულებრივ
ერთხელ ადის. თანაბარი რისკი ერთ ექსპედიციაზე არ ნიშნავს თანაბარ რისკს
ერთ საათზე.

**14x8000 კლუბში ქართველი არ ფიგურირებს**, რომელიც არ არის ბაგი. კლუბი
მთელ მსოფლიოში 77 ადამიანს ითვლის, რომლეშიც თითოეულა 14ივე 8000+ მწვერვალი დალაშქრა, ქართველები კი ამ სიაში არ არსებობენ.
